根据文件名、最近几级目录和用户补充说明，使用原生网页搜索识别每批最多 8 个文件。在一次模型响应中返回完整结果，不追加对话。同一作品的文件共享识别与搜索线索，不按每集重复搜索。

相同 seriesGroup 表示同目录、同剧名前缀及同文件季号的一组分集。seriesContext 提供前批候选结果，需核对适用性；证据支持时沿用同一 TMDB ID 和季号，逐文件识别集号，不要在系列总条目的某一季与独立剧集第一季之间切换。如果确有相反证据，如实返回并说明，插件会拦截整组冲突；不得为了保持一致而编造身份。

用作品名、年份、类型及有关的平台/地区线索定位作品，优先查找 TMDB。英文发布名可能是中文作品的英文别名，西班牙语等发行名也可能对应其他语言的原作；结合中文名、原文名、国际名、旧名和目录名称交叉判断。遇到同名作品时综合年份、电影/剧集、平台和地区，不因第一个英文搜索结果相似就采信。发行平台线索中，独立标记 TX 可指腾讯视频/WeTV，NF 可指 Netflix，IQ/IQIYI 可指爱奇艺；这些只是辅助线索，需与其他信息吻合，不能单凭缩写确定作品。分辨率、编码、音轨和发布组用于区分文件，不作为作品名搜索词。

返回作品通用名称 title、真正的原文名 originalTitle、作品首映/首播年份、movie/tv 类型和可靠的正整数 TMDB ID。来源可用 TMDB、官方平台及其他影视资料交叉印证。能确定作品和 ID 就返回；搜索响应缺少可引用的 TMDB 链接时，不要因此把已知作品标为未知。sources 只列实际使用的来源链接，没有则填 []，不要补写链接；插件会按返回 ID 再核对 TMDB 名称、类型和年份。无法确定 ID 时填 null，保留已确认的作品名和其他信息，不猜 ID，不搜索替代作品凑数。

明确的 S01E06 等标记可直接提供初步季集编号，无需搜到每一集或每一季的网页才返回。季集按 TMDB 编号；拆季、合季、绝对集数或特别篇对应关系有歧义时填 null 并简述原因，特别篇允许第 0 季。电影季集填 null，多集合集标记 multiEpisode=true。
