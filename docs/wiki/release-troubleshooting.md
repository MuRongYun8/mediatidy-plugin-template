# 发布与排错

2.0.0 是 SDK v2 改造版本，安装引用为 `v2.0.0`。源码仓库包含可安装的预打包脚本、页面和 Logo；SDK 开发包尚未发布 npm。保留旧标签，不能覆盖旧版本。

发布前运行 `npm run check` 和 `npm run pack`，提交 dist、清单、页面和 Logo。新能力需用户重新授权，不自动改本机安装。旧数据与记录保留，不执行迁移脚本。

| 现象 | 检查 |
|---|---|
| 安装提示未知能力 | 宿主必须支持 `organize.manual.run` 和 `runtime.result` |
| 模型不可用 | AI 启用、配置和插件 `ai.chat` 授权 |
| 没有联网工具 | 用户可拒绝联网；插件不自动开启 |
| 有作品名但未整理 | AI 是否给出 TMDB ID、类型和完整季集 |
| 多次模型请求 | 看逻辑轮次、工具续答、实际模型请求与兼容重发 |
| 方案变化 | 核对方案目标和行为后重新授权 |
| 整理失败或状态未知 | 先查 MT 任务；不要换幂等键自动重放 |
| Goja 工具缺失 | 设置匹配平台的 `MT_PLUGIN_RUNTIME` |
| 本地预览缺失 | `MT_PLUGIN_SDK` 指向含 `preview/` 的完整开发包 |

模拟与 Goja 测试不代表真实模型识别准确率。没有实际模型/云盘环境的项目应标为未验证。
