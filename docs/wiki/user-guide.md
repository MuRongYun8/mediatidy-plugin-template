# 使用与授权

先在 MT 配置 AI、TMDB 和一个可用整理方案。插件中心使用仓库地址 `https://github.com/MuRongYun8/mediatidy-plugin-template.git` 安装，分支／标签选择 `v2.0.0`。宿主必须支持 SDK v2 以及 `organize.manual.run`、`runtime.result`；远程旧 SDK v1 标签不能用于 SDK v2。

授予文件读取目录、整理方案、AI 对话和“按插件给出的作品和季集直接手动整理”。不需要文件正文、写入、删除或任意 HTTP 能力；整理副作用由授权方案管理。开放搜索和 TMDB 工具需要对应能力授权，拒绝它们时 AI 仍可直接识别。

运行页选择文件或目录与整理方案，可向 AI 补充线索。点击“AI 识别并整理”即开始执行：目录后台扫描，AI 每批最多识别 8 个文件，信息完整的文件逐个进入手动整理队列。不再要求宿主核验或逐次确认。方案目标和传输方式请在开始前检查。

结果保留 AI 作品、年份、类型、TMDB ID、季集、简短结论和公开来源。没有识别结果、缺少 ID/集号、异常输出、多集合集留为待处理。未提供季数默认 1，明确的 0 或其他季数保持原值。资料不足时不会让 MT 接手识别。

跨页选择后点击“重试所选待处理文件”，只重新识别未提交项。已经提交以及提交结果未知的文件会被排除。整理业务失败可能已产生部分变化，不会自动重放。

停止后续识别会停止插件流程；已入队任务仍由 MT 管理，可在业务任务区单独取消。暂停定时不会取消已执行操作。定时入口由宿主管理，新建默认停用；启用后同样直接整理。
