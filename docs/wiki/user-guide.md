# 用户指南

[返回 Wiki](README.md)

## 安装前准备

AI 识别整理需要：在 MT 配好并启用模型，配置 TMDB，创建适合来源存储类型的整理方案。本地文件使用本地方案，网盘文件使用对应云端方案；确认方案的目标目录和移动／复制方式。插件不会自动开启模型或取得模型密钥。

## 发现和安装

打开 MT 侧栏「插件中心」。默认“已安装”展示插件卡片；没有插件时，点击“浏览插件”。“发现插件”展示 MT 自带的官方目录，目前提供 AI 识别整理。详情里可读用途、前置条件、步骤、权限和仓库链接。

点击“从仓库安装”，填写：

```
仓库：https://github.com/MuRongYun8/mediatidy-plugin-template
标签：v1.1.0
```

也可在官方插件详情选择“安装 MT 内置版本”，使用随当前 MT 分发的副本。内置版本随 MT 发布，可能与远程最新版本不同。

安装分三步：

1. **读取信息**：MT 解析分支／标签，固定提交；显示实际清单，不执行仓库脚本。
2. **审阅权限与资源**：逐项勾选能力。AI 模板需勾选其声明的文件、AI、TMDB、草稿、用户确认整理与任务能力；添加所需媒体目录，选择整理方案。AI 权限表示文件名、授权目录内相对路径和说明会发送到你配置的模型服务。
3. **安装完成**：点击“配置并启用”，确认配置后勾选启用并保存。首次安装默认停用。

只授权需要使用的媒体目录。未授权能力会在运行时被后端拒绝。给插件指定的目录与整理方案，是资源范围；不会把网盘凭据交给插件。

## 打开和运行

已安装卡片显示版本、作者、来源、能力标签和启停状态。已启用插件点击“打开插件”；停用插件点击“配置并启用”。点击名称可查看概览；更多菜单提供更新、来源、回退和卸载。

独立页面的四个页签：

| 页签 | 用途 |
| --- | --- |
| 概览 | 功能、步骤、前置条件、来源与声明能力 |
| 运行 | 选择动作、文件、方案和说明，执行并查看结果 |
| 运行记录 | 按时间查看历史，打开某次运行 |
| 设置 | 配置、权限、定时运行、版本和卸载 |

在“运行”页选择文件或目录。目录递归扫描，只收集 MT 配置的视频类型，重叠选择去重，每次最多 100 个视频；超过上限需分批。选择整理方案后会显示目标目录与传输方式。可补充“这是 2009 年日剧，按文件中的第几话识别”等说明。

点击“识别并生成草稿”。此步骤只识别和核验，不整理文件。正在识别时可取消，完成后才能修正和确认。长文件名显示两行，展开“文件详情与识别依据”查看完整相对路径、AI 理由和方案。

## 修正和确认

可搜索文件／作品／错误，并筛选“待处理”“可提交”“已提交”。每页 20 项，“全选本页可提交项”只选择本页通过核验的行，跨页选择保留；底部显示总选择数量。筛选隐藏的已选项仍会包含在确认弹窗，提交前检查全部文件。

“修正”可搜索其他 TMDB 条目、修改类型、季集和方案。保存后 MT 重新核验，须重新选择并确认。作品存在但季集缺失时仍显示作品名称，错误会单独提示。多集合集不可在此强行当作一集提交。

确认弹窗逐文件展示作品、TMDB ID、季集、目标目录和移动／复制方式。“允许覆盖封存”是单独的明确选项，默认不勾选。确认前不会提交整理。未选择的文件跳过。

“已入队／已排队”只表示提交成功，后续还会显示执行中、完成、失败或取消。可以取消本插件已入队且仍可取消的整理任务。最终文件名由 MT 实际整理生成。

## 定时、更新与恢复

在运行页选好文件、动作和参数，切换设置，在定时区勾选“使用运行页当前选择…替换定时输入”，保存五段 Cron，如 `0 3 * * *`。时区为 MT 服务端时区。以后只修改 Cron／启停可保留已保存输入；首次配置需要替换输入。定时 AI 识别只生成待确认草稿，每次可能产生模型费用。

“检查更新”按当前安装来源和引用检查，可修改标签／分支。固定在 `v1.0.0` 时不会自动跟随新标签，更新到本版请填写 `v1.1.0`。审阅版本、提交和新增权限后安装。新增能力默认不授权。失败保留旧版；回退后停用，重新检查配置再启用。

停用或修改配置、授权会中断识别，旧草稿需要重新识别；已入队整理继续由 MT 管理。重启中断的提交不会自动重放，`提交结果待核对` 时先到任务中心核对。只重试待处理项会新建识别批次，不重放已提交任务。
