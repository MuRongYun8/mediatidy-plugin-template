# 插件与宿主职责

插件负责识别提示词、AI 工具循环、结果映射、逐文件整理参数和页面布局。MT 提供模型通信、公开搜索/TMDB 客户端、资源权限、持久存储、后台任务和现有手动整理。

`recognize` 接收所选文件和目录。目录交给 `files.scan`，登记 `tasks.wait` 后释放进程；`scan-complete` 收集结果并识别。文件逐批产生结果，符合参数格式的项直接调用 `organize.manual.run`。`organize-complete` 保存实际任务结论，不持续轮询或占用工作进程。

`runtime.result` 持久保存部分结果，运行页面沿完成动作链展示当前快照和统计。“排队、执行中、成功、失败、取消、结果待核对”严格区分。

业务状态位于安装实例隔离的 MT KV：`ai/v2/flow/<运行ID>` 保存流程，`ai/v2/file/<文件引用>` 保存单文件识别与任务关联。插件不建数据库、不写本机目录、不接触 MT 数据库路径。已有用户文件与插件 KV 分开管理。

JSON 页面由 MT 原有组件库渲染，不加载插件浏览器脚本。Logo 随包安装和校验，宿主没有 AI 插件 ID 专用页面或图标。
