# 安全边界

AI 仅收到文件名、授权范围内相对路径和用户说明。工具由固定分发器调用允许的 AI/TMDB 方法，模型不能给出 SDK 方法名让宿主任意执行。

插件没有系统命令、文件系统、环境变量、独立网络或数据库入口，也不申请评分、远程 FF、任意 HTTP 或文本正文读取能力。远程 FF 原文、缓存枚举、SHA1、轨道、节点配置、凭据和内部日志不进入插件模型或消息。

直接手动整理需用户授予独立能力和方案。AI 负责身份结论；宿主检查资源、参数格式、文件状态、方案修订和许可证，遵循现有封存保护。参数不足则不入队。稳定幂等键防重复提交，未知结果不自动重放。

页面按不可信 JSON 校验，文件名、模型文本、来源和错误作为文本显示。异常只返回固定业务摘要，禁止把原始异常、内部日志或敏感配置传给模型。

参阅 [MT 官方权限文档](https://murongyun8.github.io/MediaTidy-Wiki/plugins/permissions)。
